## 2. 受入 NG の原因: さいきのいのり の蘇生先の選択

- 両条件とも、パーモット (さいきのいのり) が技を成功させた直後の「蘇生する個体を選ぶ」要求 (poke-env の `reviving`、交代候補 = ひんしの個体) で、助言が候補を 1 つも返さず (`best` 空、`actions` 空)、`only_legal_action` でも決まらず、ランダム行動に退避した。
  - legacy: 対戦 52 件目 (battle-…-46567606、相手 F156)、13 ターン目。蘇生候補 2 体 (ボーマンダ・ラウドボーン) からボーマンダが選ばれた。
  - transition: 対戦 91 件目 (battle-…-46567718、相手 F059)、8 ターン目。蘇生候補はボーマンダ 1 体。唯一の合法手として扱われなかった理由は未確認 (available_moves の中身を保存していない)。
- 助言エンジンはひんしの個体を交代候補から外すので、蘇生先の選択は方式によらず常に空になる。10/15 の P2 (search 層) で 0 件だったのは、この局面が出なかっただけ。
- 退避は 7,268 / 7,663 決定中の各 1 件で、どちらの対戦も負け。結果への影響は小さいとみられるが、上限 0 の規則どおり不成立とする (規則を事後に緩めない)。
- 対応は E 節 ([KNOWN_ISSUES.md](KNOWN_ISSUES.md)) に登録: 蘇生要求のとき助言側で蘇生先を選ぶ (または説明できる飛ばしとして記録する) 測定入力の修正。

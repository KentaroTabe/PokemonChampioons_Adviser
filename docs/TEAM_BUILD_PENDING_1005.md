### 2.3 テーマのエース選出率

過去 2 run (エース = ミミロップ) の対戦記録に `theme_check` を掛けた。

| run と段 | 閾値 0.5 | 閾値 0.45 | 選出率 (高い順) |

### 2.4 較正の標本

  標本 4 並びの点は 0.862 / 0.893 / 0.919 / 0.934。保持の規則による偏りは避けられるが、点の低い並びは入らない。

### 2.7 昇格の定義

- registry の Package 12 件のうち 11 件は最終検証が 600 戦 (medium の上限)。100 戦は rule_0909 の 1 件だけ。

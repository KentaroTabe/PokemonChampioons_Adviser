# 接続テスト チェックリスト (2026-07-24 更新分)

今回の更新には「静止画・モック・ハンドラ直呼びでは検証済みだが、
実映像+実操作では未検証」の機能が含まれる。次回の接続テストで
以下を上から順に確認する。

## 0. 前提と起動

- [ ] `bash scripts/start_connection_test.sh` を実行する
      (学習ループ一時停止 → Showdown確保 → 最新コードでアドバイザー+
      フロント起動 → リアルタイム監査モニター起動 → 接続先URLの表示、
      まで一括。フレーム保存も有効。監査を省くなら `--no-audit`)
- [ ] ブラウザで表示されたURL (3000) を開き「バックエンド: 接続中」表示

## A. もっと見る画面の自パーティ自動登録 (最重要・新機能)

選出画面または交代画面で、各ポケモンにカーソル→「もっと見る」を開く。

- [ ] **能力タブ**を開く → イベントログに `my_team更新: <種族> (能力タブ)` が出る
- [ ] **ステータスタブ**へ切り替える → `my_team更新: <種族> <性格> ...` が出る
- [ ] 6体ぶん繰り返し、`config/my_team.json` に 技/特性/持ち物/能力ポイント/性格 が
      入っていることを確認 (`python -m tools.check_battle_log` ではなくファイル直接確認で良い)
- [ ] わざと素早くタブを切り替えた場合に**誤った値が保存されない**こと
      (理論値照合があるので「保存されない」が正常。`もっと見る不一致` ログが出る)
- [ ] 登録後の対戦で、ダメージ計算・素早さ比較が登録した型 (実数値) で
      行われている感触を確認 (アドバイスの被ダメ%が実測と合うか)

⚠ 既知の注意: スクショ検証は1334x750のOBS映像で実施。解像度や
圧縮率が大きく違う環境では `python -m tools.check_look_more <frame>` で
読取値を確認する。

## B. 対戦中の回帰確認 (watch抽出を再構成したため)

- [ ] 対戦中の「様子を見る」(相手詳細) が従来どおり動く
      (相手のタイプ/技/持ち物が状態に入る、誤帰属しない)
- [ ] 様子見画面の左列 (自分のHP実数値) / 右列 (相手HP%) の読み取り
- [ ] 選出画面のアドバイス、対戦中のアドバイス配信が従来どおり
- [ ] メガシンカ・交代・HP変化の追跡に退行がない

## C. 分析・コーチングパネル (フロント新設)

対戦していない時間帯に:

- [ ] 「敗因分析」→ 数秒で勝敗/負け寄与/選出別勝率/ローカルメタが表示される
- [ ] 「環境ダイジェスト」→ 使用率上位と自分の実測メタの比較が表示される
- [ ] 「直近対戦レビュー」→ 最新の勝敗確定対戦の一致率と分岐点が表示される
- [ ] 「プレイブック生成」→ 進捗が逐次流れ、1〜2分で相手構築別チャートが表示される
- [ ] 「パーティ改善案」→ 固定枠 (例: ミミッキュ) と変更上限を指定して実行し、
      固定枠が維持された改善候補が出る
- [ ] 実行中は各ボタンが無効化され、完了で復帰する

対戦中に:

- [ ] 「プレイブック生成」を押す → 「対戦中のため実行できません」が返り、
      フレーム解析が詰まらない (アドバイス遅延が出ない)

## D. 人間 vs AI 対戦 (human_battle)

- [ ] `python -m tools.export_my_team_showdown` の出力にエラーがない
      (もっと見る登録後は6体とも出力されるはず)
- [ ] `python -m tools.human_battle --name <名前> --opponent benchmark` を起動
- [ ] ブラウザで `https://play.pokemonshowdown.com/~~localhost:8100/` を開き
      同名でログイン → チャレンジが届く
- [ ] チームビルダーに export の出力を Import してフォーマット
      `[Gen 9] Champions BSS Reg MB` で受諾 → 対戦が最後まで進行する
- [ ] 終了後 `logs/human_battles.jsonl` に結果が記録される
- [ ] (余裕があれば) `--opponent model` / `--opponent search` も1戦ずつ

## E. リアルタイム監査 (既定で稼働)

- [ ] 1対戦終えて約30〜40秒後に監査が自動実行され、
      `logs/audit_reports/<対戦名>.md` が生成される
- [ ] レート画面などを開いたままでも対戦終了が検知される (レコード内容ベース判定)
- [ ] レポートの乖離一覧に本物の抽出ミスがあれば控えておく (修正候補)

## F. テスト後の確認

- [ ] `bash scripts/end_connection_test.sh` を実行する
      (監査モニター停止 → アドバイザー/フロント停止 → 学習ループ再開 →
      直近10戦のサマリー表示、まで一括)
- [ ] 表示されたサマリーに今回の対戦が反映されている
- [ ] 気づいた誤認識は `python -m tools.audit_subtask` (sonnet監査) か
      debug_frames の該当フレーム共有で報告

## 切り分けに使うコマンド

| 症状 | コマンド |
|---|---|
| もっと見るの読取がおかしい | `python -m tools.check_look_more <frame...>` |
| シーン分類がおかしい | `python -m tools.check_scene_sweep 50` |
| 抽出全般の突き合わせ | `python -m tools.audit_subtask --battle <log>` |
| チーム評価が不安定 | `python -m tools.check_team_eval` |
| human_battleが繋がらない | `python -m tools.check_human_battle` (AI対AIで疎通確認) |

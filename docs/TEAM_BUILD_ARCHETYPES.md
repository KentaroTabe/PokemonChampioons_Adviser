# 構築の軸 (archetype) 一覧 — S4 コンセプト生成のベース (確認用の案)

作成: 2026-09-18 (ユーザー確認待ち。確認後に S3〜S6 へ組み込む)。

## 0. 目的と前提

- ユーザー指摘 (9/18): 積み構築は交代すると能力変化が消えるので (バトンタッチを除き) 交代せず、壁で耐久を補うことが多い。
  いまの S4 (LLM の framing 6 種 + ルール baseline + 規則 psychic_terrain_priority_ace + 過去の勝者系統) は
  「構築の型」を網羅していない。
- 実データで確認した不足 (free_0917 の s04_concepts.json、tools/team_build の役割辞書):
  - 役割辞書に **壁役が無い** (features.py の roles は hazard / removal / priority / setup / status / pivot / speed / bulk)。
    壁技は型生成のテンプレート (attack2_screens) にあるだけで、並びの採点・制約には出てこない
  - **バトンタッチは交代技 (pivot) として数えられ**、積んで渡す役としては扱われない
  - トリックルーム・天候・フィールド (サイコ以外)・設置と削り・受けループ は軸として出ない (LLM が偶然出す範囲)
  - コンセプトは core_ids (2〜3 体) + 勝ち筋のラベルだけで、**「壁役 1 + 積みエース 2」のような役割の構造が S5/S6 に伝わらない**
- 使い方 (確認後の実装): S3 で種ごとの役割適性 (型の技・特性・持ち物・数値) を機械的に判定 → S4 で軸 × 分岐ごとに
  環境適合を採点し、役割を埋めた軸 (core) を出す (LLM にも軸ごとに提案させる) → S5 で役割の最小数を hard constraint に
  → S6 で役割の技・持ち物を型に保証 (壁役の ひかりのねんど 等) → 記事の「方向性」に軸と分岐を出す。
  判定・数値は表とデータから機械的に出し、LLM は説明と追加の仮説だけ (既存方針)。

まとめ方の判断 (確認したい点は §5):
- 「起点作り (あくび/でんじは/おきみやげ + タスキ)」と「バトンタッチ」は独立の軸にせず、積み展開の分岐にした
  (勝ち筋と交代方針が同じ)。
- 「速度操作 (おいかぜ / 加速)」は対面の分岐にした。
- 既存の LLM framing (offense / balance / bulky_offense / cycle / setup / speed_control) は軸ごとの提案に置き換える
  (LLM は軸 × 分岐の観点で core を出し、役割の構造は機械で検査する)。

## 2. 各軸の詳細

役割の判定はすべて「型の技・特性・持ち物・数値」で機械的に行う。記法: has = 代表型 (使用率) か規則のエース型に入っている、
can = champions mod の learnset で覚える (S6 で差し込める)。数値は S3 の特徴量 (先手率 = 上位脅威に先手を取れる割合、
耐久 = HP×B×D の正規化、火力 = 攻撃種族値・攻撃技の本数・タイプ数・被覆の門 = 規則のエースと同じ閾値)。

### 2.1 積み展開 (setup_sweep)
- 目的: 補助役が 1〜2 ターンを買い、積みエースが積んで抜く。**積んだ後は交代しない** (能力変化が消える)。
- 役割
  - 積みエース: 積み技 (SETUP_MOVES + 加速技) を has/can、かつ火力の門を通る。自己加速 (かそく・かるわざ) も積みに数える
  - 壁役 (分岐 2 枚壁): リフレクター と ひかりのかべ の両方を can。持ち物は ひかりのねんど (メガ石でない個体)
  - 壁役 (分岐 オーロラベール): オーロラベール を can + 雪 (ゆきふらし か ゆきげしき/さむいギャグ) を同じ並びに
  - 起点作り (分岐): あくび / でんじは / おきみやげ / すてゼリフ / 催眠 / ちょうはつ / アンコール のいずれかを has/can。持ち物は きあいのタスキ
  - バトン役 (分岐): バトンタッチ を has/can + 積み技。受け取り役 = 火力の門を通る個体 (積み技は不要)
- core (S4 に出す軸): 補助役 1 + 積みエース 2 (バトン分岐は バトン役 1 + 受け取り役 1)
- 環境適合 = 1 − 0.8 × (崩し手の重み割合)。バトン分岐は「ほえる/ふきとばし/ドラゴンテール/くろいきり/クリアスモッグ」の割合も引く
- S6 で保証: 壁役に壁技 (無ければ差し込み) + ひかりのねんど、起点作りに補助技 + タスキ、バトン役に バトンタッチ、
  エースは規則と同じ「攻撃的な代替型」の選び方
- 行動方策への含意: 積んだ後の交代を避ける。測定 (S8a〜S12) は助言操縦の RL 方策で行うため、方策が積んだ後に
  交代すると軸の価値が出ない → 構築と連動した学習 (S11b の行動 adapter) で扱う (今回は未実装、§6)
- 今期の所持候補 (§3 の集計から。~~取り消し~~ = 除外リスト)
  - 壁役 (2 枚壁): **オーロンゲ** (代表型に両方)。覚えるだけ: ギルガルド、ブリジュラス、ハラバリー、ソウブレイズ、マフォクシー、カイリュー、エルレイド、サーフゴー、キラフロル、サザンドラ、メガニウム、メタグロス、ミミッキュ、ポットデス、アシレーヌ、ライチュウ、ガラルヤドキング、ペロリーム、スターミー、ウツボット、ウルガモス、ブラッキー
  - 壁役 (オーロラベール): ~~バイバニラ~~ のみ (除外中) → 雪分岐は今の除外設定では成立しない
  - 起点作り: **カバルドン** (あくび+ステロ+ふきとばし)、**オーロンゲ** (すてゼリフ)、**ガオガエン** (すてゼリフ)、**アシレーヌ** (アンコール)、**コノヨザル** (ちょうはつ)、**ギャラドス** (ちょうはつ)、**ペロリーム/カビゴン/コータス/カエンジシ/ブラッキー** (あくび)、ラグラージ (あくび 46%)、マフォクシー (アンコール 24%)
  - 積みエース (代表型に積み技): バシャーモ (つるぎのまい+かそく)、ソウブレイズ、マフォクシー (わるだくみ)、サーフゴー (わるだくみ)、ドドゲザン、クチート、ミミッキュ、ポットデス (からをやぶる)、オオニューラ、ウルガモス (ちょうのまい)、コノヨザル (ビルドアップ)。使用率あり: ギャラドス (りゅうのまい 32%)、ミミロップ (つるぎのまい 27%)、ギルガルド (つるぎのまい 26%)、リザードン (りゅうのまい 17%)、アシレーヌ (めいそう 35%)、ライチュウ (わるだくみ 21%)
  - バトン役: **ポットデス** (からをやぶる+バトンタッチ)、バシャーモ (バトンタッチ 15%)。覚えるだけ: ガオガエン、ミミロップ、クチート、ブラッキー

### 2.2 トリックルーム (trick_room)
- 目的: 5 ターンの逆転で低速高火力が上を取る。TR 中は交代しない。
- 役割: TR 使い = トリックルーム を has/can (自分が遅ければエース兼任可)。TR エース = 火力の門 + 先手率 ≤ 0.3 (規則の TR 型と同じ閾値)
- core: TR 使い 1 + TR エース 2 (分岐 TR 使い 2 体: TR 使い 2 + エース 1)
- 環境適合 = 0.3 + 0.7 × (素早さ 100 以上の脅威の割合) − 0.5 × (ちょうはつ持ちの割合)。先制技は TR で止まらないので別途減点
- S6 で保証: TR 使いに トリックルーム、持ち物は こだわり系を避ける (ensure_setter と同じ差し替え)
- 今期の所持候補: TR 使い = ガラルヤドキング (TR 14%、素早さ 30 で自身もエース)、ミミッキュ (5%)。覚えるだけ: マフォクシー、エルレイド、マスカーニャ、ポットデス、スターミー。
  低速高火力 (素早さ 60 以下): コータス 20、ガラルヤドキング 30、カビゴン 30、ハラバリー 45、カバルドン 47、ドドゲザン 50、クチート 50 (メガで ちからもち)、ギルガルド 60、オーロンゲ 60、ガオガエン 60、アシレーヌ 60、ドデカバシ 60

### 2.3 天候 (weather)
- 役割: 始動役 = 特性 (ひでり/あめふらし/すなおこし/ゆきふらし。メガ後の特性を含む: メガリザードン Y) か 天候技。
  天候アタッカー = 特性 (ようりょくそ/サンパワー/すいすい/すなかき/すなのちから/ゆきかき) か 天候で強まる技/タイプ
  (晴れ: ほのお技・ソーラービーム、雨: みず技・かみなり/ぼうふう、砂: いわ/じめん/はがね の特防、雪: こおり技・オーロラベール)
- core: 始動役 1 + アタッカー 2
- 環境適合 = 1 − 0.8 × (天候を上書きする脅威の割合) + 0.3 × (その天候で強まるタイプが弱点の脅威の割合)
- 今期の所持候補: 晴れ = コータス (ひでり) / メガリザードン Y (ひでり)、アタッカー ウツボット (ようりょくそ)、リザードン (サンパワー 12%)。
  雨 = ペリッパー (あめふらし)、アタッカー: すいすい持ちは所持プールに代表型なし (覚える候補: イダイトウ、ガブリアス、カバルドン、ラグラージ の特性欄を要確認)。
  砂 = カバルドン (すなおこし)、アタッカー ~~ドリュウズ~~ (すなかき 31%、除外中)。雪 = ~~バイバニラ~~ (除外中)、ガラルヤドキング (さむいギャグ)

### 2.4 フィールド (terrain)
- 役割: 設置役 = メイカー特性 か フィールド技。恩恵を受けるエース = 接地 (ひこう/ふゆう/ふうせん でない) + 火力の門 +
  分岐ごとの条件 (サイコ: 先制技に弱い型 = 規則と同じ 3 型、ワイドフォース / サイコシード。グラス: グラススライダー / グラスシード。
  エレキ: ライジングボルト / エレキシード。ミスト: ミストシード / ドラゴン技を受ける役)
- core: 設置役 1 + エース 1 (+ 2 体目のエース)
- 環境適合 = 1 − 0.6 × (フィールドを上書きする割合) + (サイコのみ) 0.5 × (先制技持ちの割合)
- 既存の規則 psychic_terrain_priority_ace を指定したときはサイコ分岐が hard constraint (設置役 + エースを必ず含む)。指定が無ければ他の軸と同列
- 今期の所持候補: 設置役 (特性) = ライチュウ (サーフゴーの特性欄ではなく learnset の判定。要確認)。設置役 (技) = ハラバリー、マフォクシー、エルレイド、オーロンゲ、クチート、メガニウム、マスカーニャ、ミミッキュ、アシレーヌ、ライチュウ、ウォッシュロトム、ガラルヤドキング、ウツボット。
  サイコのエース候補は rule_0910 の判定と同じ (オオニューラ・ライチュウ・マフォクシー など)

### 2.5 設置と削り (hazard_stack)
- 役割: 設置役 = ステルスロック / まきびし / どくびし / ねばねばネット。吹き飛ばし = ほえる/ふきとばし/ドラゴンテール/くろいきり、または交代圧 (交代技)。詰め役 = 先制技持ちか速攻役
- core: 設置役 1 + 詰め役 1 (+ 吹き飛ばし)
- 環境適合 = 0.4 + 0.6 × (ステルスロックが弱点の割合) − 0.6 × (除去持ちの割合)
- 今期の所持候補: 設置 = ブリジュラス、ガブリアス、キラフロル、カバルドン、ミミズズ、ラグラージ、コータス (ステロ)、ペロリーム (ねばねばネット)、ゲッコウガ/マスカーニャ (どくびし 10%/9%)。
  吹き飛ばし = カバルドン (ふきとばし)、ブリジュラス (ほえる 31% / ドラゴンテール 22%)、ガブリアス (ドラゴンテール 27%)

### 2.6 サイクル (cycle)
- 役割: 交代技 = とんぼがえり/ボルトチェンジ/クイックターン/すてゼリフ/テレポート/さむいギャグ。受け = さいせいりょく か 回復技 + 耐久 ≥ 0.45
- core: 交代技 2 (分岐 さいせいりょく: 受け 1 + 交代技 1)
- 環境適合 = 1 − 0.6 × (設置技持ちの割合) − 0.8 × (罠特性の割合)
- 今期の所持候補: 交代技 = イダイトウ、オーロンゲ、サザンドラ、ガオガエン、マスカーニャ、ペリッパー、ウォッシュロトム、ガラルヤドキング、スターミー、ラグラージ、ハラバリー (ボルトチェンジ 63%)。受け = ガラルヤドキング (さいせいりょく)、カバルドン (なまける 38%)、カイリュー/サーフゴー/ハラバリー (回復技)

### 2.7 受けループ (stall)
- 役割: 高耐久 = 耐久 ≥ 0.45 + 回復技 (or さいせいりょく)。状態異常 = どくどく/おにび/でんじは/あくび
- core: 高耐久 2 (+ 状態異常役)
- 環境適合 = 1 − 0.7 × (積み技持ちの割合) − 0.5 × (ちょうはつ・アンコール持ちの割合)
- 今期の所持候補: ブラッキー 0.77 (ねがいごと)、ギルガルド 0.69、カビゴン 0.67 (ねむる 35%)、カバルドン 0.67 (なまける 38%)、コータス 0.64、ガラルヤドキング 0.63、ハラバリー 0.62 (なまける)、ガオガエン 0.62、ウォッシュロトム 0.61、メガニウム 0.60 (こうごうせい)。
  今期は積み技持ちの脅威が重み 56% で、この軸の適合は低い (§3)

### 2.8 対面 (hyper_offense)
- 役割: 速攻役 = 火力の門 + (先手率 ≥ 0.6 か タスキ/スカーフ)。先制技 = 先制技持ちの攻撃役。おいかぜ役 (分岐)。自己加速役 (分岐) = かそく/かるわざ/加速技
- core: 速攻役 2 (分岐 おいかぜ: おいかぜ役 1 + 速攻役 1、自己加速: 自己加速役 2)
- 環境適合 = 1 − 0.4 × (先制技持ちの割合) − 0.3 × (交代技持ちの割合)
- 今期の所持候補: 素早さ 100 以上 = ガブリアス 151 (メガ Z)、ゲッコウガ 142、ミミロップ 135、マフォクシー 134、ライチュウ 130、カエンジシ 126、マスカーニャ 123、スターミー 120、オオニューラ 120、ムクホーク 110、メタグロス 110、ウルガモス/ガルーラ/カイリュー/リザードン/バシャーモ 100。
  おいかぜ = ペリッパー (15%)、覚える: カイリュー、サザンドラ、ムクホーク、ドデカバシ、ウルガモス。自己加速 = バシャーモ (かそく)、ペロリーム/オオニューラ (かるわざ)、ポットデス (からをやぶる)、ウルガモス (ちょうのまい)

### 2.9 低速高火力と先制技 (priority_bulky)
- 役割: 先制技持ちの高火力 = 先制技 has + 火力の門 (1 体は耐久 ≥ 0.35)。削り役 = 設置役か状態異常役
- core: 先制技持ち 2 (分岐 ふいうち: ふいうち持ちを 1 体含む、鋼先制: バレットパンチ/マッハパンチ 持ちを 1 体含む)
- 環境適合 = 0.5 + 0.5 × (素早さ 100 以上の割合) − 0.9 × (先制技を無効にする特性・サイコフィールドの割合)
- 今期の所持候補: ふいうち = ガルーラ、ドドゲザン、クチート、ヒスイダイケンキ、ウツボット、マスカーニャ (23%)。
  鋼/その他の先制 = メタグロス (バレットパンチ)、ミミロップ (マッハパンチ)、カイリュー (しんそく)、ギルガルド/ソウブレイズ/エルレイド/ミミッキュ (かげうち)、イダイトウ/アシレーヌ/スターミー (アクアジェット)

### 2.10 環境上位への回答 (anti_meta)
- 役割: 上位 5 脅威 (重み順) への被覆 ≥ 0.6 の個体 (S3 の coverage)。core = そのうち被覆の重みつき和が最大の 2 体
- 環境適合 = 1 (材料は脅威の重み)。既存の rule:anti_meta の framing を軸として明示するもの
- 今期の上位 5: ボーマンダ (59)、ガブリアス (59)、ブリジュラス (34)、アシレーヌ (27)、カバルドン (22)

- 測定の起動の落とし穴 (入力ではなく条件): check_advisor_player の --models-dir は rl_bridge (遅延 import) にしか効かず、相手の操縦 (ModelPlayer) と選出モデルの埋め込みは import 時の config.MODELS_DIR (環境変数 CHAMPIONS_MODELS_DIR) を使う。環境変数なしで直接起動すると、本体の作業ツリーでは本番の checkpoints を、ワークツリーでは存在しないパスを読む (後者は相手がランダム合法手になる。この診断の組 rand)。10/13 の P1 は usefulness_p1 が子プロセスの環境変数で渡しているので影響なし

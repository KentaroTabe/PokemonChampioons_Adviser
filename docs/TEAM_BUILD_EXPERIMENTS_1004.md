# 検証実験 1〜4 の結果と、変更案 29 項目の評価 (2026-10-04)

構築システム (`tools/team_build`) の「切り分けの見直し」に伴う検証実験 4 本を実行した結果と、同時に出された
変更案 29 項目 (A 目的と前提 / B 評価と較正 / C LLM の役割 / D 探索と測定の予算 / E 整理) への評価をまとめる。
評価は「今あるデータと費用で実行できるか」という現実面に絞っている。採否はユーザー判断で、この文書は判断の材料。

- 実験のコード: `tools/team_build/experiments/` (コミット 293ab245、統合ブランチへは e0b91683 でマージ)。
- 結果ファイル: `logs/build_search/experiments/{calibration,concept_origin,env_validity,llm_audit}.json`。
- 「補足」と書いた集計は、同じデータに作業用スクリプト (読み取りのみ、リポジトリ外) を掛けたもの。方法は各節に書く。

用語: Δ = 参照チーム (今の登録チーム) との勝率差。最初のふるい = S8a (300 戦)。最終比較 = S10 (600 戦)。
最終検証 = 封印した相手での holdout。ρ = 順位相関 (Spearman)。κ = 偶然の一致を除いた一致度 (Cohen)。

## 1. 実験の結果

### 1.1 実験 1: 代理評価の較正の予備試験

探索段が並びにつける点 (被覆などの項の重みつき和) が、測定した Δ の順位をどれだけ説明するかを run ごとに見る。
1 本の run を外して残りで重みを当てはめ直し、外した run で既定の重みと比べる。

| run | 方式 | 測定チーム | ρ (既定の重み) | ρ (当てはめた重み) | 当てはめで選ばれた被覆の重み |
|---|---|---|---|---|---|
| ace_lopunny_1002d | 従来 | 10 | −0.383 | +0.122 | 0 |
| arch_0918 | 従来 | 7 | +0.571 | +0.500 | 0 |
| arch_0924 | 従来 | 7 | +0.393 | +0.321 | 0 |
| free_0917 | 従来 | 8 | −0.405 | −0.119 | 0 |
| ace_lopunny_1003 | 同時探索 | 10 | −0.097 | (run が 1 本で当てはめ不可) | — |

- 判定: **不採用**。従来方式は使える run が 4 本 (規則は 5 本以上)、同時探索は 1 本。
- 従来方式の 4 回の当てはめは、どれも主項である被覆の重みを 0 にした。改善は 4 本中 2 本 (中央値 +0.107)。
- 同じ 6 体が複数の run で測られたときの Δ の標準偏差は中央値 0.040 (4 チーム)。現行チームは 4 run で
  +0.067 / +0.002 / +0.010 / −0.010。参照や相手プールが run ごとに違うので、純粋な測定誤差だけの値ではない。
- 補足 (採否規則の検定力): 代理の項と Δ が無関係な世界で同じ手順を回すと、規則の最小条件 (5 run × 8 チーム、
  中央値の改善 ≥ 0.1、改善する run ≥ 2/3) で **17.7% が「採用」** になった (300 回。項は従来方式 4 run の測定チーム 32 から再標本化、
  Δ は同じ 32 個から独立に引く、乱数の種 20261004)。中央値の改善の 5%〜95% は −0.230〜+0.388。

補足 (指摘の正しさ)。データで機械的に確かめられる 4 カテゴリについて、多数決の指摘を図鑑データと突き合わせた。

| | Sonnet | Haiku |
|---|---|---|
| 指摘 (4 カテゴリの合計) | 40 | 40 |

- 配分・役割の 2 カテゴリ (Sonnet の指摘 21 件と 11 件) は主観で、全件は確かめていない。
  見た例は妥当だった (攻撃役で主攻撃の配分が 8、積み役の雛形なのに技が 3 つで積み技なし、など)。

(ゴリランダー、コータス、ニョロトノなど)。baton_blaziken_1004 の合法な 97 並びのうち 22 (23%) がそういう型を含む。

## 2. 変更案 29 項目の評価

### 総評

1. **実験に委ねた判断が、今のデータ量では決まらない。** 項目 8・11・12・13 が該当する。同時探索の run は 1 本、
   LLM と軸の測定数は 14 対 13、同じ並びの実戦は 16 戦 (訂正前 17)。
2. **最大の実測差は並びではなく選出モデル。** 現行チームのシム勝率は production の選出モデルで 0.417、適応し直すと 0.73。
   他の項目が扱う差は ±0.05 以下で、run 間のゆらぎ (0.04) と同程度。
3. **1 run 約 22 時間と LLM $23 が全ての検証の律速。** 較正に 5 run、昇格に 3 run が要る。費用を削る項目 (23、13、20) は
   勝率の証拠なしで実施できるので、先にやる方が得。
4. **表の「現状」に事実と違う記述があり (1、24)、未測定の変更が既定 on になっている (25、22)。**

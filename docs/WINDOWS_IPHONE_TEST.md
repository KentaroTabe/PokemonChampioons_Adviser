# Windows PC + iPhone でのテスト手順

iPhone版ポケモンチャンピオンズの画面をWindows PCにミラーリングし、
本システム (リアルタイム対戦アドバイザー) をテストする人向けの手順書。

> **重要な前提**: 開発環境はmacOS (OCRにApple Visionを使用) です。
> WindowsではOCRが自動的に**EasyOCRフォールバック**になり、
> 日本語の小さい文字の認識精度が下がります (開発時の実測では
> ポケモン名の誤読が増える)。「動くが精度は本家より落ちる」前提で
> テストし、誤認識は画面の✏️ボタンで手動修正してください。

## 必要なもの

- Windows 10/11 PC (メモリ8GB以上推奨。EasyOCRが初回にモデルをDLします)
- iPhone (ポケモンチャンピオンズ導入済み) と同一Wi-Fi
- [OBS Studio](https://obsproject.com/) (無料)
- AirPlayレシーバーソフト (例: LetsView、LonelyScreen など。
  iPhone画面をPCのウィンドウに映せれば何でも良い)
- Python 3.9〜3.11 / Git

## 1. セットアップ

```powershell
git clone <このリポジトリ>
cd PokemonChampioons_Adviser
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-core.txt
```

初回起動時にEasyOCRが認識モデル (数百MB) をダウンロードします。

## 2. iPhone画面をOBSに取り込む

1. AirPlayレシーバーソフトをPCで起動する
2. iPhoneのコントロールセンター → 画面ミラーリング → PCを選択
3. OBSでソース「**ウィンドウキャプチャ**」を追加し、
   ミラーリング画面のウィンドウを選択
4. **キャンバス/出力解像度を1920x1080に設定する** (設定 → 映像)。
   720p以下では文字が潰れて認識できません (実測済み)
5. iPhoneの画面がキャンバスいっぱいに映るよう拡大配置する
   (上下の黒帯はOK、ゲーム画面の左右が切れるのはNG)
6. OBSの「**仮想カメラ開始**」を押す

## 3. サーバーの起動 (PowerShellで2つ)

```powershell
# ターミナル1: アドバイザーサーバー (ポート8000)
.venv\Scripts\activate
$env:PYTHONUNBUFFERED=1
uvicorn server:app_asgi --host 0.0.0.0 --port 8000
```

```powershell
# ターミナル2: フロントエンド配信 (ポート3000)
python -m http.server 3000
```

起動ログに「準備完了」が出ればOK。`DEBUG_DUMP_FRAMES=1` を環境変数に
設定すると受信フレームが `debug_frames/` に保存されます (不具合報告用に推奨)。

## 4. ブラウザで接続

1. http://localhost:3000 を開く
2. カメラ選択で「**OBS Virtual Camera**」を選ぶ
3. 右上の接続チップが「バックエンド: 接続中」(緑) になることを確認
4. iPhoneでランクバトルを開始する

## 5. テストで確認してほしいこと

| 画面 | 期待される動作 |
|---|---|
| 選出画面 | 相手6体のタイプ表示 / 種族の推測 (不明はプルダウンで候補選択可) / 自分の選出3体と選出順の認識 / 選出提案の表示 |
| コマンド選択 | アドバイス (推奨行動・🎲択評価・被ダメ予測) が数秒で更新される |
| 対戦中 | 技・特性・持ち物・HP変化がイベントログに流れる |
| 試合終了 | 勝敗の記録と📊パーティ診断の自動表示 |
| 誤認識時 | 各ポケモンの✏️ボタン、場の状態チップのクリックで手動修正できる |

パーティ登録: 「パーティ編集」ボタンから自分の6体 (種族/性格/能力ポイント
/持ち物/技) を登録すると、ダメージ計算が実際の型で行われます。

## 6. うまくいかないとき

- **「接続失敗」**: ターミナル1のuvicornが起動しているか確認
- **映像が映らない**: OBSの仮想カメラが開始されているか、
  ブラウザのカメラ許可を確認
- **文字化け・誤認識が多い**: OBSの出力が1080pか確認。EasyOCRの
  限界もあるため、✏️で修正しつつ `logs/battles/*.jsonl` を提出してもらえると
  改善に使えます (修正操作は自動で記録されています)
- **画面が紫/ピンクに寄って色がおかしい**: タイプアイコンの誤認が増えます。
  OBS側の色空間設定 (NV12/709) を既定値に戻してください

## 7. フィードバックの送り方

以下を添えて報告してください:
1. `logs/battles/` の該当試合の `.jsonl`
2. (あれば) `debug_frames/` の該当時刻のPNG数枚
3. 現象の説明 (「選出画面で〇〇が△△と表示された」等)

## 制限事項 (Windows環境)

- OCR精度がmacOS (Apple Vision) より低い
- 強化学習 (champions_agent) はテスト対象外 (Showdownのセットアップが別途必要)
- `scripts/*.sh` はbash用のため使用しない (本書のPowerShellコマンドを使う)

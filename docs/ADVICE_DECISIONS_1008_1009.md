## 2. 注記

### 2.1 分母の定義 (監査が行動イベントと結び付けた決定であり、映像中の全決定ではない)

- 決定 = ログの events 行で、`fired` に `move_player_*` または `switch_player` を含むもの。ただし先発の繰り出し
  (決定画面も battle 助言もまだ観測していない時点の `switch_player`) は数えない。**行動が events に記録されなかった手番は分母に入らない**ので、
  69 件は映像中の全決定の下限である (取りこぼした手番の数は未測定)。
- events に記録される行動は**実行された技**であり、選択した技とは限らない。アンコールで置換された場合などは実行技が記録される (9a-T2、§5)。
- ひんし後の繰り出し (自分の個体が倒れた後の交代) も 1 決定に数える。助言の注記が「ひんし: 交代先を選んでください」となった決定は 11 件 (一致 4)、
  助言がひんしを認識できず技を推したままの決定が 1 件 (9f-T4b、一致なし)。**一致率 37.7% には、この 12 件 (一致 4) が含まれる**。助言がひんし後と判断しなかった 58 件
  (自発の交代 4 件と 9f-T4b を含む) では一致 22 件 (37.9%)。分母の違う値は混ぜない。
- 「一致」は、決定の間 (前の決定の行動イベント以降) に出た確定済み battle 助言の**いずれか**の第一候補との一致である。最終助言の第一候補だけと比べると一致は 24 件
  (24/69 = 34.8%)。差の 2 件 (9b-T4、9c-T5) は「前の第一候補」経由の一致で、9c-T5 はプレイヤーの技 (きょけんとつげき) が最終助言の候補に無い。
- 同じ戦の同じ turn に複数の決定が現れる組が 8 組ある (9a の turn 3 は 4 決定、8c の turn 4 は 3 決定など)。turn は単独のキーにならない。ID は同じ turn の決定に a, b, … を付けた。
- 助言の第一候補は、前の第一候補の据え置き (差 6 未満) により最高点とは限らない。最終助言で第2位が第一候補より高い点だったのは 2 件 (8d-T4 は一致、9d-T5 は不一致)。

### 2.5 キーと欄の読み方

- キー: `ログ名:t:L<行>`。ログ名は `battle_` と `.jsonl` を除いたもの。t は行動イベント (events 行) の t、L は**ファイルの行番号** (1 始まり)。
  advice_id は `<ログ名>-NNNN` の NNNN 部分だけを、その決定の間に出た確定済み battle 助言すべてについて並べた (確定前 provisional の助言は監査と同じく数えない)。
- 場面・自分の場・相手の場・上位 3 は**最終助言**(決定の直前に出た最後の助言) の記録に基づく。個体は `和名(種族 id)[メガ] HP%`。メガは state の mega フラグで、種族 id は基本形のまま (§5 の 9d-T5・9e-T5・9f-T4 を参照)。
- 不確かさ: 「HP古」= 場の HP が最後に実際に読めてからの秒数 (hp_stale)、「HP未読」= 一度も読めていない、「自HPバー推定」= my_hp_estimated、
  「相手対応待ち」= opp_pending、「相技既知」= 相手の場の個体の判明技の数。
- 順位は最終助言の actions の中でのプレイヤーの行動の順位。候補に無ければ「候補外」。

## 6. 補足: 本表の作成で気づいたこと

- メガ進化した自分の個体 (カメックス・ボーマンダ・ミミロップ) は、state では `mega=true` のまま種族 id が基本形である (相手側は `golisopodmega` などの形態 id になる)。
  素早さの推定値でメガ形態との不整合を確かめられたのはミミロップだけ (172、メガなら 205。計画書 §1.3)。カメックスはメガで素早さ種族値が変わらず (78)、ボーマンダ (100→120) は推定 135 から基本形かメガ形態かを判別できなかったため、本表では確かめていない。
- ダメージ予測と実測の差: 相手がグソクムシャの 8b-T5a・8d-T10 で、インファイトの予測 56〜67% (いまひとつ) に対し実測が 80%・95%。
  助言の注記には「メガグソクムシャ 98% の見込み」とあり、メガ後のタイプ変化を予測に使っていないか確認が要る (未確認)。
- 9a の turn 3 の 4 決定 (a〜d) のうち、アンコールが絡むのは a だけ (9a-T2 の読取もアンコール)。b〜d はアンコールと無関係なので、初版の 9a T3 は a と判断した。

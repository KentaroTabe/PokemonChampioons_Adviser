# 課題台帳 (機能別・ファミリー別)

接続テスト第2〜11回・監査・インシデントの記録から、欠陥を**個別事象ではなく
ファミリー**として整理した台帳。状態は
✅解消 (再発防止テストあり) / 🟡緩和 (主経路は塞いだが残余あり) /
👁 要観察 (要求は有効だが今すぐ確実に改善できない。観察条件を明記) の3値。
更新は接続テストの終了処理・監査のたびに行う。詳細な経緯は
docs/CONNECTION_TEST_CHECKLIST.md と docs/incidents/ を参照。

## A. 対戦情報の認識・抽出

### A1. メッセージ取り逃しファミリー (最重要・構造的)

**構造**: ゲームのメッセージは演出中に1〜2秒で流れ、処理落ちで破棄された
フレームの情報は永久に失われていた (負荷時54-76%破棄の実測)。
「メッセージを読んで状態を更新する」設計は原理的に不完全で、
(1) **確実に取れる情報源からの決定的反映**、(2) **破棄フレームからの
救出バッファ** (2026-08-31: 軽量トリガーでメッセージ/ポップアップ域を
退避し非同期OCR — キャプチャと処理の分離)、(3) 定点での照合、の三層へ
設計を移した。

**測定基盤 (2026-08-31 新設)**: `scripts/advice_replay.sh` — 決定再生
ハーネスで「認識誤り→推奨反転率」をフィールド別に実測できる。初回
(120決定点): 自分HP固着28.1% / 相手判明技消失23.9% / 相手HP固着20.7% /
選出フラグ消失18.9% / 相手ひんし見逃し10.2% (高マージン反転0)。
**認識投資の優先順位はこの表に従う** (件数の多さではなく提案への影響順)。

| 情報 | 対応 | 状態 |
|---|---|---|
| 能力ランク変化 | 技・交代イベントから確定分を即時反映 (boost_moves.json 100%発動のみ+いかく)。場の状況画面が補正役 | ✅ (第9回) |
| 持ち物の発動 | 効果表 item_effects.json (69種) で消費・回復・ランク変化を反映。しろいハーブ/ふうせんは推定発動も | ✅ (第9回) |
| いのちのたま反動 | 持ち物確定+ダメージ技イベントで-10%を決定的反映 | ✅ (第10回) |
| 勝敗 | ランク画面キー (resultシーン化で遅延解消) + レート差分推定 (小数3桁対応) + ひんし数推定の3段 | ✅ (第7-10回) |
| **ひんし** | faintメッセージ+ゼロ読み裏付け (HUD/一覧/側柱) に加え、**残数ボールとの照合**で取り逃しを補完 (2回読み確認つき、低HP非アクティブのみ確定) | 🟡 (2026-08-31 照合を追加。**候補を特定できない取り逃し** — 高HP表示のまま消えた個体 — はログ警告のみ。観察条件: faint_deficit_* イベントの頻度) |
| 対戦中のHP残量 | 毎フレームHUD読み+watch側柱+種族可能域検証。**表示が無い時間帯の被弾** (ムクホーク100%固着) は原理的に取れない | 👁 (要求有効。残数照合と交代メニュー読みで実害を削減。観察条件: 監査のHP固着件数) |

### A2. シーン誤分類ファミリー

**構造**: 色ヒューリスティクス分類器の特徴が画面間で重なる。分類器の
全面改修より「**OCRアンカーで画面を確定** (field_check/準備中/result方式) +
**誤分類しても実害が出ない抽出側ゲート**」の二層で対処する方針
(2026-08-22 に watch 系の分類分離を断念した判断を維持)。

| 事象 | 対応 | 状態 |
|---|---|---|
| ランク結果画面→command/field | resultシーン新設 (実フレーム321枚で検証、誤吸収ゼロ) | ✅ (第10回) |
| メニュー画面 (お知らせ/ボックス/バトルメニュー等)→field の誤イベント | **対戦文脈ゲート** (2026-08-31): battle_active または選出直後でなければ field のメッセージOCRを流さない。誤分類自体は残るが誤イベント経路を遮断 | 🟡 (分類の混同は未解消。実害が再発したら該当画面のOCRアンカー追加で個別に潰す) |
| 技リスト/技説明/つよさ表示→command/watch/move_select | 抽出側ガード (書き込み条件・2フレーム裏付け・種族可能域) で実害を遮断 | 👁 (分類正解が要求なら分類器改修が必要だが、実害ベースでは現ガードで十分。観察条件: 監査の乖離のうち実害を伴う件数) |

# 外部構築の取り込み

選出モデルの汎化はチームの「種類」で頭打ちになる。ラダーのオープンデータだけでは
272種が上限なので、構築記事などから集めた構築をここに足して種類を増やす。

## 使い方

1. 構築を `inbox/` にテキストで置く (1ファイルに何チーム入れても良い)
2. `bash scripts/import_teams.sh champions_agent/data/teams/inbox/xxx.txt`
3. `python -m tools.team_sources` で合計チーム数を確認
4. `bash scripts/collect_selection.sh 8 2500 ranked` で収集し直す

## テキストの形式

1行1体で「種族名」または「種族名 @ 持ち物」。日本語名・英語名・showdown ID の
いずれでも良い。6体そろうと1チームとして確定する。

```
# source: https://example.com/articles/12345
カイリュー @ こだわりハチマキ
ミミッキュ
ガブリアス @ ヤチェのみ
ゲッコウガ
ブリジュラス
ハラバリー
```

Showdown のエクスポート形式をそのまま貼っても、種族行以外
(`Ability:` / `EVs:` / `- 技` など) は読み飛ばすので動く。
`# source:` 行と `===` 行はチームの区切りも兼ねるので、
6体そろっていない書きかけはそこで捨てられる。

## 技・特性・性格・努力値について

記事ごとの調整は再現せず、`meta_sets` にあるその種族の最多構成で補完する。
ラダー構築と同じ経路なので、外部構築とラダー構築が同じ土俵に載る。
選出モデルの特徴量は種族埋め込みが主なので、この粒度で足りる。

## 取得についての注意

構築記事サイトは自動収集を規約で禁じているところが多い。本ツールは
**手元に用意したテキストを取り込むだけで、取得は一切行わない**。
取得元は `source` として記録し、どこ由来のデータかを後から追えるようにしている。

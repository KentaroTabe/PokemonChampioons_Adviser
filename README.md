# ポケモン対戦 AIアドバイザーシステム - ミラーリング及びキャプチャ基盤

このドキュメントでは、iPhoneの実機で動作している対戦画面をMacへ低遅延でミラーリングし、システム（ブラウザ/バックエンド）に映像を取り込むための手順を説明します。

## アーキテクチャ概要

本システムでは、安定性と低遅延を確保するため、有線接続とOBS Studioの「仮想カメラ」機能を利用します。

1. **iPhone → Mac**: QuickTime Playerではなく、OBS Studioを使って直接映像を取り込みます。
2. **OBS → Mac (OS)**: OBSの「仮想カメラ」機能により、ゲーム画面をWebカメラとしてOSに認識させます。
3. **Mac → Browser**: フロントエンド（React / Vanilla JS）の `getUserMedia` APIを使用して、仮想カメラから映像を取得します。
4. **Browser → Backend**: Canvas APIで定期的に静止画を切り出し、WebSocket経由でPythonバックエンドへ送信します。

## 前提条件（必要なもの）

*   Mac本体
*   iPhone（ゲーム稼働用）
*   iPhoneとMacを接続する有線ケーブル（USB-C または Lightning）
    *   *※AirPlay等の無線接続は、遅延とブロックノイズによるOCR精度低下を招くため非推奨です。*
*   [OBS Studio](https://obsproject.com/ja) (Mac版 Ver 26.1以降推奨)

---

## 手順1：OBS Studioによるミラーリングと仮想カメラの起動

1.  iPhoneとMacをケーブルで接続します。
    *   *初回接続時は、iPhone側で「このコンピュータを信頼しますか？」というダイアログが表示されるので「信頼」を選択してください。*
2.  Macで **OBS Studio** を起動します。
3.  画面下部の「ソース」パネルの左下にある **「＋」ボタン** をクリックし、**「映像キャプチャデバイス」** を選択します。
4.  デバイスのドロップダウンリストから、接続した **iPhoneの名前** を選択します。
5.  プレビュー画面にiPhoneの映像（ゲーム画面）が表示されます。映像がキャンバス全体にぴったり収まるように、赤い枠をドラッグしてサイズを調整します（上下左右に黒帯が入らないようにしてください）。
6.  画面右下の「コントロール」ドック内にある **「仮想カメラ開始」 (Start Virtual Camera)** をクリックします。
    *   *※Mac版OBSで初めて仮想カメラを開始する場合、管理者パスワードを求められることがあります。パスワードを入力して許可してください。*

## 手順2：パフォーマンスとOCR精度のための解像度調整

システムの負荷を下げ、かつOCR（EasyOCR）が安定して数値を読み取れる最適な解像度に調整します。

1.  OBS画面右下の **「設定」** をクリックします。
2.  左側メニューから **「映像」** タブを選択します。
3.  以下の設定値に変更します。
    *   **基本 (キャンバス) 解像度**: `1280x720`
    *   **出力 (スケーリング) 解像度**: `1280x720`
    *   **FPS 共通値**: `10` 〜 `30` （ターン制ゲームの解析において60FPSは不要です。負荷軽減のため下げてください）
4.  「適用」または「OK」をクリックして設定を保存します。
5.  *※仮想カメラが起動中の場合は、一度「仮想カメラ停止」を押し、再度「仮想カメラ開始」を押すことで新しい解像度が確実に適用されます。*

## 手順3：フロントエンドでの映像取得確認

フロントエンド側の実装（`index.html` または Reactコンポーネント）において、ブラウザから仮想カメラの映像が正しく取得できるか確認します。

1.  カメラへのアクセスを行うため、システムを起動する際はローカルサーバーを経由してアクセスしてください。
    *   例: `python3 -m http.server 8000` を実行し、`http://localhost:8000` にアクセス。
2.  ブラウザで「カメラへのアクセス」を求められたら **「許可」** をクリックします。
3.  URLバーの右端にあるカメラアイコン（またはブラウザの設定）から、使用するカメラとして **「OBS Virtual Camera」** が選択されていることを確認します。

### 映像取得用コードスニペット例 (JavaScript)

```javascript
// OBS仮想カメラ(1280x720)から映像を取得する例
const stream = await navigator.mediaDevices.getUserMedia({
    video: {
        width: { ideal: 1280 },
        height: { ideal: 720 }
    },
    audio: false
});

const videoElement = document.getElementById('video');
videoElement.srcObject = stream;

```

## トラブルシューティング

* **ブラウザのカメラ選択リストに「OBS Virtual Camera」が出ない**
* OBS側で仮想カメラを開始した状態のまま、ブラウザ（Chrome等）を一度完全に終了（`Command + Q`）し、再起動してください。


* **「Tainted Canvas」や「Unsafe attempt to load URL」というエラーが出る**
* HTMLファイルをダブルクリック（`file:///...`）で直接開いているため、セキュリティ制限に引っかかっています。必ずローカルサーバー（`localhost`）を立ち上げてアクセスしてください。
